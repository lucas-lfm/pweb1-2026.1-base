# Projeto Didático RetroMarket

O projeto RetroMarket é um projeto didático que visa ensinar conceitos de análise e projeto de sistemas e desenvolvimento web backend. Ele é estruturado em várias etapas de modelagem, cada uma focada em diferentes aspectos do sistema, desde a visão funcional até a implementação da API REST.

## Documentação do Projeto

A documentação do projeto é organizada em várias etapas, cada uma abordando um aspecto específico do sistema. As etapas incluem:

1. **Diagrama de Casos de Uso** — visão funcional do sistema, mostrando como os usuários interagem com o sistema.
2. **Especificação dos principais Casos de Uso** — detalhamento dos fluxos de cada caso de uso, incluindo pré-condições, pós-condições e exceções.
3. **Modelo Conceitual de Domínio** — definição dos conceitos e relacionamentos do domínio do sistema, representando a estrutura de dados e as entidades envolvidas.
4. **Diagrama de Classes Conceitual** — representação da estrutura estática do domínio, mostrando as classes, atributos e relacionamentos.
5. **Diagrama ER Lógico** — representação da persistência dos dados, mostrando as tabelas, chaves primárias e estrangeiras, e os relacionamentos entre elas.
6. **Diagrama de Atividades** — representação dos processos selecionados, mostrando o fluxo de atividades e decisões dentro do sistema.
7. **Diagrama de Sequência** — representação do comportamento e interação entre os objetos do sistema ao longo do tempo, mostrando a ordem das mensagens trocadas.
8. **Diagrama de Arquitetura** — representação da estrutura da aplicação, mostrando os componentes, camadas e a comunicação entre eles.
9. **Diagrama de Classes da Aplicação** — detalhamento das classes da aplicação, incluindo Controller, Service, Repository, DTO e outros componentes, mostrando como eles se relacionam e interagem.
10. **Contrato da API REST** — definição da interface da API REST, incluindo os endpoints, métodos HTTP, parâmetros, respostas e códigos de status, servindo como a ponte final para a integração com o frontend (PWEB I).

Nesta pasta, você encontrará os artefatos correspondentes a cada uma dessas etapas, permitindo uma compreensão abrangente da modelagem do projeto RetroMarket desde a concepção até aspectos de implementação.

> Utilizem este material como referência e estudo para o desenvolvimento do projeto final das disciplinas de análise e projeto de sistemas e programação web 1.
